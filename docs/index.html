Windows: mikrofonni albatta tanlang

Windows'da standart qurilma ba'zan «Stereo Mix» bo'lib qoladi — u ovozingizni emas, kompyuterdagi ovozni yozadi va tushunarsiz matn chiqaradi.

Ilova birinchi ochilishda Sozlamalarni ko'rsatadi va bunday qurilmalarni ogohlantirib beradi. Bluetooth quloqchin ham aniqlikni pasaytiradi — imkon bo'lsa oddiy mikrofon ishlating.

Windows: «Model yuklab olinmadi» xatosi chiqsa

785 MB fayl uchun barqaror internet kerak. Ulanish uzilsa o'rnatuvchi uch marta qayta uradi, keyin xato beradi. Ikkita yechim bor:

  • To'liq versiyani yuklab oling — model uning ichida, internet umuman kerak emas (yuqoridagi havola)
  • Yoki modelni alohida yuklab oling (brauzer yoki yuklab olish menejeri bilan — ular uzilishdan keyin davom ettiradi), so'ng ggml-rubaistt.bin faylini setup.exe turgan papkaga qo'ying va o'rnatuvchini qayta ishga tushiring. U faylni o'zi topadi.
Windows: «Windows protected your PC» chiqsa

Ilova hali kod imzosi sertifikati bilan imzolanmagan, shuning uchun Windows ehtiyot bo'ladi. Bir martalik yechim:

  • «Batafsil» / «More info» tugmasini bosing
  • Keyin «Baribir ishga tushirish» / «Run anyway»
macOS: birinchi ochishda ogohlantirish chiqsa

Ilova Developer ID bilan imzolangan, lekin hali Apple notarizatsiyasidan o'tmagan. Birinchi marta:

  • macOS 13–14: ilovaga o'ng tugma (Control-click) → Open → Open
  • macOS 15: System Settings → Privacy & Security → pastga → «Open Anyway»

Bir marta shunday qilsangiz, keyin doim normal ochiladi.

macOS: Accessibility ruxsati

Matn avtomatik joylashishi uchun bir marta ruxsat kerak: System Settings → Privacy & Security → Accessibility → «Audio-Matnga» ni qo'shing va yoqing.

Windows'da bunday ruxsat kerak emas.
